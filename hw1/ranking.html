What is Ranking?

After webpages have been crawled and indexed, search engines must decide which results should appear first when someone performs a search. This process is called ranking.

When a user enters a query, the search engine looks through its index and finds many possible matches. Ranking algorithms then determine the order in which those results will appear on the search results page.

Common Ranking Factors

Search engines use hundreds of signals to evaluate webpages. Although the exact ranking formula is not public, several important factors are known.

  • Relevance of the page to the search query
  • Quality and usefulness of the page content
  • Mobile friendliness
  • Website speed and performance
  • Secure connections using HTTPS
  • Core Web Vitals such as load time and visual stability

Personalized Search Results

Search engines also adjust results based on the user's context. Factors such as location, device type, language, and previous searches can influence which pages appear first.

For example, searching for "weather" will usually show the forecast for your current location. If you search on a smartphone, search engines may prioritize websites that are optimized for mobile devices.
